# Ownership в Rust и три правила владения

## Что такое ownership

**Ownership** (владение) — это **статическая модель управления ресурсами** в Rust. Компилятор **отслеживает**, какой **binding** отвечает за **освобождение** значения, и **автоматически** вставляет вызов **деструктора** (`drop`) в точке выхода владельца из области видимости.

**Ключевое:** **никакого GC**, **никакого runtime** — все проверки на **этапе компиляции**.

## Три правила ownership

### 1. У каждого значения — **ровно один** владелец

```rust
let s = String::from("hello");   // s — владелец
```

- У `String` **один** владелец — `s`.
- **Не может** быть **двух** владельцев **одного** значения.

### 2. В один момент времени владелец **только один** — передача называется **move**

```rust
let s1 = String::from("hello");
let s2 = s1;   // ← move: владение переходит к s2

// println!("{}", s1);   // ❌ ошибка: s1 больше не владелец
println!("{}", s2);      // ✅
```

- **После move** — **исходный** binding **инвалидируется**.
- **Компилятор** **запрещает** использование `s1`.

### 3. Когда владелец **выходит** из скобок — значение **дропается**

```rust
{
    let s = String::from("hello");
    // s — владелец
}   // ← здесь вызывается drop(s), память освобождается
```

- **Автоматически** вызывается `drop`.
- **Компилятор** вставляет **вызов** в **точке выхода** из области видимости.

## Разбор примера

```rust
fn take(s: String) {
    println!("s: {}", s);
}

fn main() {
    let my_string = "Hello, world!".to_string();

    take(my_string);   // ← move: владение переходит в take

    // my_string;      // ❌ ошибка: use of moved value
}
```

### Что происходит

1. **`my_string`** — **владелец** `String`.
2. **`take(my_string)`** — **move** владения в `take`.
3. **Внутри `take`** — `s` **владелец**.
4. **После `take`** — `s` **дропается**.
5. **`my_string`** в `main` — **инвалидирован**.

### Ошибка при использовании

```
error[E0382]: use of moved value: `my_string`
 --> src/main.rs:8:5
  |
6 |     let my_string = "Hello, world!".to_string();
  |         --------- move occurs because `my_string` has type `String`,
  |                   which does not implement the `Copy` trait
7 |     take(my_string);
  |          --------- value moved here
8 |     my_string;
  |     ^^^^^^^^^ value used here after move
```

**Компилятор** **точно указывает**:

- где **создан**;
- где **перемещён**;
- где **использован после move**.

## Что такое move

**Move** — **побайтовое копирование** стекового представления + **инвалидация** исходного binding **на этапе компиляции**.

### Для `String`

```rust
let s1 = String::from("hello");
let s2 = s1;
```

**`String`** — **три** машинных слова:

| Поле | Что |
|---|---|
| **ptr** | указатель на данные в куче |
| **len** | длина |
| **cap** | ёмкость |

**Move** копирует **эти три слова** (24 байта на 64-битной системе) — **без** копирования **кучи**.

### Схема

```
До move:
s1: [ptr]───┐
    [len]   │
    [cap]   │
            ↓
        [heap: "hello"]

После move:
s1: (инвалидирован)
s2: [ptr]───┐
    [len]   │
    [cap]   │
            ↓
        [heap: "hello"]   ← те же данные
```

**Куча не копируется** — **только** указатель.

## Move vs Clone

| | Move | Clone |
|---|---|---|
| **Что копирует** | Стековое представление | **Глубокое** копирование |
| **Куча** | ❌ Не копируется | ✅ Копируется |
| **Стоимость** | Дёшево | Дорого |
| **Исходный binding** | Инвалидирован | Валиден |
| **Требует** | — | `impl Clone` |

### Пример: `Clone`

```rust
let s1 = String::from("hello");
let s2 = s1.clone();   // ← глубокое копирование

println!("{}", s1);   // ✅ s1 валиден
println!("{}", s2);   // ✅ s2 — копия
```

**Куча** **копируется** — **два** независимых `String`.

## `Copy` — исключение из move

**`Copy`**-типы **копируются** **побитово** — **исходный** binding **остаётся валидным**:

```rust
let x = 42;
let y = x;   // ← копия, не move

println!("{}", x);   // ✅ 42
println!("{}", y);   // ✅ 42
```

**`Copy`** реализуют:

- **примитивы** (`i32`, `bool`, `char`, `f64`);
- **ссылки** `&T`;
- **кортежи** из `Copy`;
- **массивы** из `Copy`.

### `Copy` и `Drop` — **взаимоисключающие**

```rust
#[derive(Copy)]
struct MyType { }   // ← нельзя, если есть Drop
```

**Ошибка:**

```
error[E0184]: the trait `Copy` cannot be implemented for this type;
              the type has a destructor
```

**Причина:** `Copy` **неявно** **дублирует** значение → **два** `drop` на **одну** память → **двойное** освобождение.

## Сводная таблица

| Тип | Поведение при присваивании |
|---|---|
| `i32`, `bool`, `char` | **Copy** — копия |
| `&T` | **Copy** — копия |
| `[i32; 5]` | **Copy** — копия |
| `(i32, i32)` | **Copy** — копия |
| **`String`** | **Move** — перемещение |
| **`Vec<T>`** | **Move** — перемещение |
| **`Box<T>`** | **Move** — перемещение |
| **`File`** | **Move** — перемещение |
| `Rc<T>`, `Arc<T>` | **Clone** (не Copy) — счётчик |

## Сводная таблица трёх правил

| # | Правило | Что означает |
|---|---|---|
| **1** | Один владелец | У значения — **ровно один** owner |
| **2** | Один в момент времени | Передача = **move**, старый **инвалидирован** |
| **3** | Drop при выходе | Владелец вышел → **drop** |

## Полный пример

```rust
fn take(s: String) {
    println!("s: {}", s);
}   // ← drop(s)

fn main() {
    let my_string = "Hello, world!".to_string();   // владелец

    take(my_string);   // move → take
    // my_string инвалидирован

    // my_string;   // ❌ use of moved value

    // ✅ Правильно: клонировать
    let another = "Hello".to_string();
    take(another.clone());   // копия передаётся
    println!("{}", another); // ✅ another валиден
}
```

## Итог

- **Ownership** — **статическая** модель управления ресурсами.
- **Три правила:**
  1. **Один** владелец у значения.
  2. **Один** в момент времени; передача = **move**.
  3. **Drop** при выходе владельца из скобок.
- **Move** — **побайтовое** копирование **стекового** представления + **инвалидация** binding.
- **Куча** при move **не копируется**.
- **Clone** — **глубокое** копирование (куча тоже).
- **`Copy`** — **побитовое** копирование; **исходный** binding **валиден**.
- **`Copy` и `Drop`** — **взаимоисключающие**.
- **Никакого GC**, **никакого runtime** — всё **на этапе компиляции**.
- **Исключения:** `Rc<T>`, `Arc<T>` — **счётчики ссылок**.
- **Правило:** после move — **исходный** binding **недоступен**; для **копии** — `clone()`.
